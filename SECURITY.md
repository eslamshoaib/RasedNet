# Security Policy · سياسة الأمان

## Reporting a vulnerability · الإبلاغ عن ثغرة

**English —** RasedNet is a security tool, so we take vulnerabilities seriously.
Please report them **privately**, not in a public issue:

- Use GitHub's **"Report a vulnerability"** button under the repository's
  **Security** tab (private vulnerability reporting is enabled).
- Please include: affected version/commit, a description, steps to reproduce,
  and impact. We aim to acknowledge reports promptly.

Do **not** test RasedNet against systems you do not own or are not authorized to
assess. RasedNet is intended only for authorized networks.

**عربي —** راصد أداة أمنية، ونأخذ الثغرات بجدية. من فضلك أبلِغ عنها **بشكل خاص**
وليس في issue عامة:

- استخدم زرّ **"Report a vulnerability"** في تبويب **Security** بالمستودع.
- اذكر: الإصدار/الـ commit المتأثّر، وصف المشكلة، خطوات إعادة إنتاجها، والأثر.

لا تختبر راصد على أنظمة لا تملكها أو لست مُصرّحاً لك بتقييمها.

## Supported versions · الإصدارات المدعومة

The latest released version on the `main` branch is the supported version.
آخر إصدار منشور على فرع `main` هو الإصدار المدعوم.
